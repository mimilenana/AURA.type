## Easing functions — `src/lib/easings.js`

The easing functions are the [`eases`](https://github.com/mattdesl/eases)
package by Matt DesLauriers, consolidated into a single file and converted to
ES modules. The curves themselves are Robert Penner's easing equations, which
almost every animation library builds on.

[easings.net](https://easings.net) is an excellent visual reference for these
curves — worth keeping open while you work. It is only a reference: the site's
own source is GPL-3.0 and none of it is reproduced here.
